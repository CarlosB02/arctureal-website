# Preferências e Regras do Projeto

- Nunca abras o browser / host para verificar tarefas simples (como CSS, estilização, textos, pequenos ajustes visuais ou de código).
- Apenas deves abrir o browser se o utilizador pedir explicitamente para testar/ver em direto ou para fluxos complexos interativos.
- NUNCA executes comandos de Git (commits, merges, branches, worktrees, pull, push). O utilizador gere o versionamento exclusivamente pelo GitHub Desktop.
